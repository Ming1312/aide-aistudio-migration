# 01 功能與頁面清單（來源：本機最新完整版 1.1.0-rc3，不是雲端裁剪版）

> 來源是專案根目錄的 `app/`（`streamlit_app.py` 的 16 個頁面、`app/views/` 22 個檔案）與 `src/`（112 個模組）。
> 雲端版（Phase 6.2）只是這個版本的唯讀裁剪；遷移以**本機完整版**為準。

## 3. 橫切功能（每個頁面都要有）

| 功能 | 舊實作 | 遷移要求 |
|---|---|---|
| 資料版本標示 | `ui588.version_badge`：全站同一個版本徽章；版本一變所有頁面同步 | 每頁頂端同一個元件；版本來自引擎 |
| 真實資料來源與使用聲明（新增） | 舊系統只有 `config/data_provenance.json`（來源與授權欄位為空） | 常駐『資料來源與使用聲明』頁：使用者聲明（2026-11-20）、來源（競賽方提供／無公開下載網址）、授權（無標準授權；證據＝使用者聲明）、尚未提供的外部證明 |
| 合成資料標示 | 每頁『含合成資料』標籤；批次檔 SYNTHETIC／NOT_REAL_DATA 標記 | **強制**：合成資料永遠帶 `__synthetic`；任何圖表／表格／Gemini 解釋都要標示；不得與真實資料混在同一個圖例 |
| 角色與權限 | `app/access.py`＋`p62_access`：預設唯讀；管理者用密碼雜湊解鎖；5 次錯誤鎖定；沒設定管理者時全唯讀（fail closed） | Node 伺服器端驗證管理者（密碼雜湊放 Secrets）；所有 W 端點只接受『伺服器簽發』的管理者身分 |
| 雲端暫存聲明 | `p62_cloud.CLOUD_LIMITS` | 部署在 AI Studio／Cloud Run 時，若儲存是暫存的，介面必須明講『不會永久保存』 |
| 長時間運算進度 | `ui60.run_with_progress`（真實進度、已花時間、預估剩餘）；`warmup` 預先載入 | 長任務（決策時間線、檢查所有場域、重訓）要有進度；可用 job＋輪詢 |
| 錯誤處理 | 明確錯誤訊息；不白畫面 | 引擎不可用時降級為『預計算（離線）』並標示 |
| 限制聲明 | 『不控制設備』、『歷史回放不是即時』、『探索性、未獨立驗證』、『單位為推測』 | 逐字保留（見 `docs/06` 驗收） |
| 稽核 | 版本庫 `audit.jsonl` 雜湊鏈；預測紀錄、模型事件各自雜湊鏈；決策紀錄；審查紀錄 | 引擎保留；前端提供『稽核檢視』與『驗證完整性』 |

## 4. 會『寫入』的操作（遷移後必須全部經過引擎，且只有管理者可用）

| 操作 | 舊函式 | 寫到哪裡 | 防護 |
|---|---|---|---|
| 驗證上傳（stage） | `p586_store.Store.stage` | 版本庫 quarantine＋稽核 | PII 掃描、BLOCK 不改 current |
| 核准寫入（commit） | `Store.commit` | 版本庫新版本＋manifest＋current | 兩步驟原子提交；中途當機可 recover |
| 版本回復 | `Store.rollback` | current 指標＋稽核 | 不刪任何版本 |
| 保存預測 | `p588_ledger.Ledger.record` | `predictions.jsonl`（雜湊鏈） | 冪等 |
| 比對真值 | `Ledger.reconcile` | `outcomes.jsonl` | 真值被更正時追加 revision |
| 重新訓練 | `p589_retrain.retrain`（外包 `p59_guard.guarded_retrain`） | `models/<task>/vNNNN` | 凍結配方；疑似故障擋下；需『確認原因』覆寫 |
| 啟用／回復模型 | `p589_registry.Registry.promote／rollback` | `active.json`＋`registry.jsonl` | experimental 才允許；formal 永遠被 `formal_gate` 擋 |
| 記錄模擬處置 | `action_logger.ActionLogger.record_human_decision` | 決策紀錄 | 只能 `human_simulation`；拒絕 `verified_real_action` |
| 審查問題 | `p53_review.ReviewStore` | 審查紀錄 | 暱稱制、PII 與路徑擋下 |

## 5. 新增功能（舊系統沒有）

* **Gemini 自然語言解釋**（N）：解釋資料、預測、異常與證據。規則（見 `docs/08`）：只能引用引擎回傳的事實；不得發明數字；合成資料一律標示；不得宣稱準確度；不得建議控制設備。
* 下載（C）：目前畫面的資料／圖表資料以 CSV 下載（真實資料帶 `__real`、合成資料帶 `__synthetic`；兩者分開）。
* 七場域完整真實資料探索（C）：圖表、篩選、欄位說明、時間資訊（缺口、時區未標示）——舊系統只在『資料探索與分析』頁提供，新系統不需要引擎即可使用。
