## 原則
1. 舊 Streamlit 網站、GitHub 備份、`outputs/phase6_2/backup_pre_6.2/` 全部保持原樣；新網站是**新增**，不是覆蓋。
2. 每個階段結束要有**可重跑的驗收證據**（腳本輸出），不是口頭。
3. 引擎內任何演算法都不改；要改先走舊系統的測試與凍結程序。
4. 不用假預測：沒有引擎就顯示『離線預計算』或『目前無法預測』，不顯示湊出來的數字。
5. 付費資源（Cloud Run、Cloud Storage…）由你決定何時建立；本次沒有建立任何雲端資源。
